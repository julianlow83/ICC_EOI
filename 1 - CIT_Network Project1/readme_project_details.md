#### Hardware
Each group will have access to the following hardware to create your prototype topology:
* **3x** Cisco Routers
* **3x** Cisco Switches
* **5x** Workstations
* Cables as required

An additional pre-configured Cisco Router will be provided to simulate your internet services. The configuration of this router can only be changed after seeking permission from the ISP (your teacher) and must be accompanied by an explanation of the change *(keep in mind, most ISPs will not make changes to their network for a single customer)*.

---

### Requirements
* Cable the network according to Cisco design best practice.
* Establish full Layer 3 reachability between all sites.
* Use static routing.
* Configure VLANs and inter-VLAN routing.
* Configure Layer 2 and Layer 3 security.
* Harden all devices.
* Configure site-to-site VPN (using GRE over IPsec).
* Implement 802.1X.
* Configure DHCP and NTP.
* Justify and test all decisions.
